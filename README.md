# Софія збирає своїх

Локальный сайт-приглашение: React, TypeScript, Vite и GSAP. Дизайн — экспериментальная афиша с flash-фотографией.

## Запуск

```sh
npm ci
npm run dev -- --port 5182
```

Откройте http://127.0.0.1:5182. `npm run build` — production-сборка в `dist/`, `npm run lint` — ESLint, `npm run typecheck` — TypeScript, `npm test` — Playwright (Chrome). `npm run preview -- --port 5182` — просмотр сборки.

## Изменение события

Все данные находятся в `src/config.ts`: имя, дата с часовым смещением, часовой пояс, локация, дресс-код, программа, сообщение, фото, дедлайн, `allowPlusOne`. При изменении события обновите также title/description в index.html. Поля venue/address/routeUrl пустые: маршрут появляется только с местом и HTTPS-ссылкой. Фото находятся в public/images; описания сцен — в design.md.

RSVP сохраняется только в localStorage текущего браузера. Сервер и отправка организатору не подключены. Ответ можно изменить; браузер с запрещённым хранилищем получает понятное сообщение. Календарь скачивается как настоящий ICS с UTC-временем (дата события настроена на Europe/Kyiv).

Галерея поддерживает свайп и увеличение, Escape закрывает модальное окно. Вступление можно пропустить и повторить внизу. Для reduced motion используется статический билет с явной кнопкой открытия. Полноценный сайт доступен без вступительной анимации.

Демо-фотографии созданы встроенным imagegen, это визуальный мудборд, а не фотографии реального события или именинницы. Сторонние сервисы и отправка RSVP организатору не подключены. Шрифты хранятся локально в сборке.

## Подготовка к GitHub и Vercel

Используйте `npm ci` для воспроизводимой установки. Для статического Vite-проекта команда сборки — `npm run build`, выходная папка — `dist`. Серверные переменные и секреты этому сайту не нужны; секреты нельзя помещать в клиентские `VITE_*`-переменные. Deploy сайта выполняется только по отдельной команде владельца.

Перед push: проверить состав файлов, секреты, `git status` и diff, затем выполнить lint, typecheck, тесты и сборку. Скриншоты и отчёты создаются в игнорируемых папках и не входят в исходники. Не включайте `node_modules`, `dist`, `.env*`, логи и кэши; `package-lock.json` необходимо сохранять.

## Репозиторий

Код: [elizabeth445/dr2](https://github.com/elizabeth445/dr2), основная ветка `main`. Пользователь заранее разрешил для этого проекта автоматический коммит и push после каждой успешно завершённой задачи на изменение сайта. Полный порядок проверок и ограничения записаны в `AGENTS.md`. Это разрешение не включает самостоятельный deploy сайта.

Если Node.js отсутствует в PATH на рабочем компьютере, перед командами npm можно подключить локальный runtime: `source ~/.codex/bin/frontend-env.sh`.
